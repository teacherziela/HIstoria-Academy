# Historia Academy — The Lost Scrolls
Prototaip permainan Sejarah Tingkatan 1 Bab 7 untuk GitHub Pages.

## Hosting GitHub Pages
1. Cipta repository baru, contohnya `historia-academy`.
2. Upload `index.html` dan `questions.js` ke root repository.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Tunggu GitHub Pages menerbitkan laman.

## Bank soalan
Edit `questions.js`. Sistem mengacak soalan dan kedudukan pilihan jawapan ketika permainan berjalan.
